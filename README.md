# Engenharia de Software & Desenvolvimento Web | Portfólio Técnico 🚀

Este repositório centraliza o ecossistema de aplicações e sistemas desenvolvidos por **Kauã Henrique Tolentino Nunes** durante a graduação em Análise e Desenvolvimento de Sistemas em Brasília. 

O objetivo deste espaço é consolidar e documentar a aplicação prática de conceitos fundamentais de engenharia de software, arquitetura de sistemas, modelagem de dados e governança de código através do versionamento profissional com Git.

---

## 📂 Governança e Estrutura do Repositório

Visando a manutenibilidade e a segmentação de responsabilidades, o repositório é estruturado em diretórios independentes para cada solução descrita no portfólio:

* **`/villa-gourmet`**: Ecossistema web voltado para a gestão operacional de restaurantes. Focado na estruturação de código semântico e gerenciamento de fluxos de dados complexos.
* **`/bolso-facil`**: Aplicação de inteligência financeira e controle logístico pessoal. Focado na resolução de problemas lógicos e tradução de regras de negócio em algoritmos de alta performance.

---

## 🛠️ Stack Tecnológica & Core Competencies

A construção das soluções contidas neste repositório baseia-se em tecnologias consolidadas no mercado de tecnologia, divididas por camadas de especialidade:

* **Camada de Interface (Front-End Moderno):** Construção de interfaces e componentes do zero utilizando a base estrutural da web: HTML5 estruturado, CSS3 responsivo e lógica client-side em JavaScript puro.
* **Camada de Negócio (Back-End & Algoritmos):** Desenvolvimento focado em orientação a objetos, modularidade e robustez lógica utilizando a linguagem Java.
* **Camada de Persistência (Banco de Dados):** Modelagem de dados relacionais, estruturação de tabelas e otimização de consultas (queries) utilizando MySQL.
* **Controle de Versão:** Arquitetura de versionamento profissional utilizando Git e GitHub para o rastreio histórico de commits e documentação técnica.

---

## 🧠 Engenharia de Processos Aplicada

Os projetos aqui hospedados demonstram o domínio em competências críticas que vão além da escrita de código:

1. **Análise de Requisitos e Modelagem:** Capacidade de extrair necessidades de cenários reais (como o setor de alimentação e logística financeira) e transformá-las em especificações técnicas de software.
2. **Estruturação de Código e Clean Code:** Preocupação contínua com a organização, legibilidade e semântica do código para facilitar a escalabilidade dos sistemas.
3. **Resolução de Problemas Lógicos:** Aplicação de estruturas de repetição, condicionais e tratamento de dados para garantir cálculos e fluxos de tela 100% precisos.
